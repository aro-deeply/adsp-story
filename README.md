# ADsP 이해 노트

ADsP 18개 단원을 단원마다 하나의 이야기와 그림으로 풀어 낸 **이해용** 앱이에요. 문제 풀이와 단어장은 공부용 앱에서 따로 해요.

- 주소: https://aro-deeply.github.io/adsp-story/
- 휴대폰: 주소를 연 뒤 브라우저 메뉴의 "홈 화면에 추가"를 누르면 앱처럼 쓸 수 있어요. 한 번 열어 두면 인터넷이 없어도 열려요.

## 과목별 주인공

- 1과목 데이터 이해: 동네 편의점 사장님
- 2과목 데이터 분석 기획: 커피 프랜차이즈 본사 김 팀장
- 3과목 데이터 분석: 입시학원 원장님

## 파일 구조

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 실제 앱. **직접 고치지 말고** `build.py`로 만든다 |
| `u/u01.html` ~ `u/u18.html` | 단원별 내용 (HTML 조각). 내용을 고칠 때는 여기 |
| `base.css` | 단원 내용 공통 스타일 (색, 그림, 카드) |
| `shell.html` | 앱 틀 (홈 화면, 단원 이동, 읽음 표시) |
| `src/` | 원본 자료 (공부용 앱의 단원 데이터) |
| `SPEC.md` | 단원 페이지 작성 규칙 |
| `sw.js`, `manifest.json`, `icons/` | 홈 화면 추가와 오프라인용 |

## 고치는 법

1. `u/uXX.html`(내용) 또는 `shell.html`(앱 틀)을 고친다.
2. `python build.py` 를 실행하면 `index.html`이 새로 만들어지고, 오프라인 캐시 버전도 자동으로 바뀐다.
3. 커밋하고 푸시하면 1~2분 뒤 주소에 반영된다.

로컬 미리보기: `python -m http.server 8790` 후 `http://127.0.0.1:8790/`

## 메모

- 13장 회귀 결과표와 14장 주성분분석 표의 일부 칸은 교재에 없는 숫자로, 표 읽기 연습용으로 교재 숫자에 맞춰 채운 예시다 (페이지에도 표시).
- 읽음 표시는 기기의 브라우저에만 저장된다.
